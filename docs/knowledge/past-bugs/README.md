# Past Bugs

This folder records notable bugs that were found and fixed in this project.

Each file documents one bug: its symptom, root cause, fix, and how to prevent recurrence.

---

## Purpose

- Prevent the same bug from being introduced again
- Give future engineers and agents context for non-obvious behavior
- Provide a regression test reference

---

## File naming

`<YYYY-MM-DD>-<slug>.md`

Example: `2026-05-10-room-schema-mismatch-crash.md`

---

## Template

Use `templates/regression-template.md`.

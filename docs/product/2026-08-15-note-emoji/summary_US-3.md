## Slice Scope

US-3 delivers exact Unicode Recent persistence across repository/app recreation, recoverable empty Recent fallback, Hilt wiring, production picker Recent rendering, and real Android glyph/visual validation. It must preserve the existing US-1 insertion path and US-2 catalog behavior without adding note schema, API, DTO, or permission changes.

## Key Decisions

- Store the exact selected Unicode sequence, including skin-tone modifiers, as a bounded device-local MRU list through the domain repository contract and DataStore implementation.
- Keep Recent persistence separate from note content; only inserted emoji continue through the existing note document save/sync/share/export path.
- Use the existing Material 3 bottom sheet and semantic design-system tokens; no feature-specific design exception is approved.
- Treat missing Android runtime/font evidence as a loud gate failure, never as a skipped pass.
